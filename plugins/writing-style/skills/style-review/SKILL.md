name: style-review
description: 文章スタイルルールを1ルール1エージェントで並列チェックする。文章・記事・ドキュメントのスタイルレビューを求められたときに使う。
argument-hint: "[検査対象の Markdown ファイルパス]"
---

対象ファイル: $ARGUMENTS（未指定の場合は、どのファイルを検査するかユーザーに確認してから始める）

次の手順で文章スタイルのレビューを実行する。

1. `${CLAUDE_SKILL_DIR}/references/rules.md` を読み、ルールを1項目ずつ抽出する（グループ見出しではなく `- ` で始まる項目単位）
2. ルール1項目につき `style-rule-checker` サブエージェントを1つ起動する。**全ルールぶんを並列で**起動し、各エージェントには「対象ファイルのパス」と「担当するルール1項目の全文」だけを渡す。他のルールは渡さない
3. 全エージェントの結果を集約し、ルールごとに違反箇所を報告する。複数のルールが同じ箇所を指摘した場合は、その旨を明記して1つにまとめる
4. 修正は行わない。報告だけ行い、どれを直すかはユーザーが判断する
